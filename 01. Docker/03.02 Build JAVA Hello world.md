# Creating a JAVA Hello world Docker container

1. Download files from the folder:   
        [03.02 Build JAVA Hello world](./03.02%20Build%20JAVA%20Hello%20world/)

1. Create a folder for building the Docker image:  
 
        mkdir ~/Docker/java-hello-world

2. Put into the folder file:   
        [HelloWorld.java](./03.02%20Build%20JAVA%20Hello%20world/HelloWorld.java)

3. Run:  

        javac HelloWorld.java

5. Put in the folder the file:  
        [Dockerfile](./03.02%20Build%20JAVA%20Hello%20world/Dockerfile)

6. Run:  

        docker build -t my-java-hello-world:1.0 .

7. Run one of:  

        docker run my-java-hello-world:1.0
        
        docker run --rm --name hw my-java-hello-world:1.0
