# Creating a JAVA REST API web service Docker container

1. Download files from the folder:      
        [03.03 Build JAVA web service](./03.03%20Build%20JAVA%20web%20service/)

1. Create folder for building Docker image: 
        
        mkdir ~/Docker/java-web-service

2. Put in folder the file:      
        [RestWebService.java](./03.03%20Build%20JAVA%20web%20service/RestWebService.java)

3. Run:

        javac RestWebService.java

5. Put in folder file:  
        [Dockerfile](./03.03%20Build%20JAVA%20web%20service/Dockerfile)

6. Run:

        docker build -t java-web-service:1.0 .

7. Run one of:

        docker run --name jws -d -p 5050:5050 java-web-service:1.0
        
        docker run --name jws -d -p 0.0.0.0:5050:5050 java-web-service:1.0
