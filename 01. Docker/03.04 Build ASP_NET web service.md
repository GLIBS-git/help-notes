# Creating a ASP .NET core REST API web service Docker container

1. Create folder for building Docker image: 

        mkdir ~/Docker/cs-web-service

2. Put in folder the whole ASP.NET web service project:     
        [cs-hello-web-app](https://github.com/GLIBS-git/cs-hello-web-app/)

3. Run:

        docker build -t cs-web-service:1.0 .

4. Run one of:

        docker run --name csws -d -p 5050:5050 cs-web-service:1.0
    
        docker run --name csws -d -p 0.0.0.0:5050:5050 cs-web-service:1.0
